# Security policy

**FlowRail v0.1 is an experimental prototype, not security-audited software.**

## Reporting vulnerabilities

If GitHub's private vulnerability reporting is enabled, use the repository Security tab and privately report the issue. Otherwise, contact the repository owner via a private channel they explicitly publish. Do not publicly post exploitation instructions or secrets.

## Baseline commitments

- No administrator permissions, antivirus exceptions, or OS-protection bypasses.
- No credential collection, keystroke recording or tracking.
- No mandatory network connection or backend.
- Minimal local configuration and explicit provider permissions.
- No downloaded third-party native plugin execution in the prototype.
- Audit, signing and reproducibility efforts are planned, not yet validated.
